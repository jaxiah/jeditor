# Project Guidelines

- **Language**: All file content (source code, comments, documentation) must be in English.
- **Communication**: Use Chinese for interactive dialogue with the user, but preserve English for technical terminology.
- **Git Workflow**: Execute a `git commit` after every completed ISSUE.
- **Implementation**: Prefer functional programming idioms in OCaml. Refer to Helix or Zed for architectural/UX inspiration when uncertain.
